Entrar

O painel salva os projetos direto no seu repositório do GitHub. Para isso, ele precisa de um token de acesso.

Configurações do repositório
Como criar o token (só uma vez)
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Dê um nome (ex.: painel-portfolio) e escolha a validade.
  3. Em Repository access, marque Only select repositories e escolha Portifolio.
  4. Em Permissions → Repository permissions → Contents, escolha Read and write.
  5. Clique em Generate token, copie e cole aqui.

Nunca compartilhe esse token nem coloque ele no código.
